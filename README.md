# 💫 About Me

Hi! I'm Sohham, a Software Engineer passionate about building intelligent systems that combine AI with robust software engineering.

My primary interests lie in:

- 🤖 Generative AI & LLMs
- 🧠 Agentic AI Systems
- 🔍 Retrieval & Knowledge Graphs
- ⚙️ Distributed Systems
- 📈 AI Infrastructure & Observability
- 🚀 Developer Productivity

I enjoy building systems that make AI practical for real-world applications—from LLM orchestration frameworks and retrieval pipelines to debugging platforms, infrastructure tooling, and developer experiences.

Recently, I've been exploring:

- Multi-Agent Architectures
- Context Engineering
- Model Context Protocol (MCP)
- Long Context Optimization
- RAG & GraphRAG
- AI Evaluation
- Open-source AI Infrastructure

I believe the most interesting engineering happens at the intersection of research and production, where ideas become scalable, maintainable systems.
